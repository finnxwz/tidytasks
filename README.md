# TidyTasks

**Automatically move completed tasks to the bottom of each Markdown task list, keeping subtasks attached and surrounding text in place.**

Open tasks come first, in-progress tasks follow, and completed tasks come last. Within the completed group, the most recently completed task appears first.

![TidyTasks Demo](https://raw.githubusercontent.com/finnxwz/tidytasks/main/tidytasks-demo.gif)
## 🖱️ How to use

- After downloading and activating TidyTasks, you're all set. Every new list now sorts itself automatically.
- Lists that existed before installation will also sort themselves the next time a task’s status changes (just tick a checkbox and untick it again).
- You can also exclude specific notes from automatic sorting with right-clicking on them in the file browser and selecting “Exclude note from automatic sorting”.


## 💡 Additional info

I’ve added some settings to the plugin menu that let you personalize your TidyTasks experience:
- **Automatic sorting:** turn automatic sorting on or off for your entire vault.
- **Sort automatically in this note:** turn automatic sorting on or off for the note you currently have open (same effect as right-clicking it and selecting “Exclude note from automatic sorting”).
- **Typing delay:** change how long TidyTasks waits without further edits before it sorts, in case the default 500 ms is too fast or too slow for you.
